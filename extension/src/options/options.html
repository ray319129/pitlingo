開始使用（三個步驟）

  1. 在下方填入你的 Anthropic API key

    沒有金鑰就不會翻譯。一場兩小時的正賽約花 US$0.3～0.4（依 Anthropic 當時價格）。

  2. F1TV 的英文字幕（CC）會自動開啟

    PitLingo 需要它開著才能顯示中文，進入每一支影片時會自動幫你打開。若畫面提示沒有字幕，到播放器右下角齒輪 → Subtitles → Language 選 English。

  3. 打開任一支影片

    其餘步驟皆為自動。重播會先把整支影片的字幕翻好；同一支影片看第二次直接用本機快取，不再花錢。

Anthropic API key

PitLingo 開源版用你自己的 Anthropic API key 翻譯，費用直接記在你的 Anthropic 帳戶。 到 Anthropic Console 建立一把金鑰，貼在下面。

金鑰只存在這台電腦的瀏覽器（chrome.storage.local），只會送到 api.anthropic.com，不會傳給任何其他地方。 建議在 Console 替這把金鑰設定每月花費上限。

F1TV 官方字幕本身時快時慢，這裡可以自己補。
往左（延後，最多 3 秒）任何情況都有效。往右（提前，最多 2 秒）只在重播有效—— 直播的字幕清單是滑動視窗，基準點會變，強行提前只會顯示錯位的字幕。 重播也需要先播一段讓它自動校準；校準不穩定時會自動退回「只延後」。
換一支影片會自動回到「跟隨官方字幕」——每支影片的偏差都不一樣， 把上一支調好的值帶過來，預設就是錯的。字級與位置則會保留。

關於字幕延遲

F1TV 的英文字幕本身即比語音晚約 0.5 秒出現，中文字幕依據該英文字幕翻譯，因此會一併延後相同時間。

遇到問題：在 F1TV 分頁按 F12 → Console 左上角把 top 切到 PitLingo， 執行 __pitlingo.diag()，把結果附在 GitHub issue 裡。
